# Мизан

Курс арабской морфологии (сарф) по учебнику «التصريف» (на основе «العزي في التصريف»). Работает прямо в браузере, удобнее всего с телефона.

- 16 уроков, каждый в 5 шагов: текст автора с переводом → объяснение и таблицы учебника → разбор примеров → вопросы учебника (أسئلة) с ответами → задания учебника (تمارين) с проверкой и ответами
- спрягатель: прошедшее, мудари‘, с لَنْ и لَمْ, повеление, оба залога
- справочник: таблицы и термины из учебника

Весь курс — в файле `index.html`. Прогресс ученика хранится в его браузере, аккаунты не нужны.

## Файлы сайта

Кроме `index.html` в папке лежат файлы приложения: с ними сайт ставится на телефон как приложение и открывается без интернета. Шрифты лежат в папке `fonts`, поэтому сайт не зависит от Google Fonts. Загружайте на GitHub всё вместе: `index.html`, `manifest.webmanifest`, `sw.js`, четыре картинки `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` и папку `fonts` целиком (её можно перетащить в окно загрузки вместе с файлами).

При обновлении обычно меняется только `index.html`. Если после сборки изменились шрифты или иконки, загрузите заново и их.

## Как выложить на GitHub Pages

1. Зайдите на github.com и создайте новый репозиторий: **New repository**. Название любое, например `mizan`. Тип — **Public**.
2. На странице репозитория нажмите **Add file → Upload files** и перетащите всё из этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, четыре картинки `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` и папку `fonts` целиком (её можно перетащить в окно загрузки вместе с файлами), а также `README.md` и `.nojekyll`.
   Если `.nojekyll` не видно (скрытый файл), его можно пропустить: сайт работает и без него.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите:
   Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)**. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/mizan/`. Ссылка появится вверху страницы **Settings → Pages**.

## Как обновить

Загрузите новый `index.html` через **Add file → Upload files** с тем же именем: GitHub заменит старый файл. Прогресс учеников сохранится, если адрес сайта не меняется.
